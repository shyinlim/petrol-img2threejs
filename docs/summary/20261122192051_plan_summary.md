## 1. 為什麼有 v11

1. 使用者紅框指出 10 處和 v3 的差距。
2. 雨棚要改 Caltex 官方紅色，加一角白色斜紋。
3. 預設鏡頭太低太近，CALTEX 字擠在一起，旗子被面板擋住。
4. UI 有中文，標題字型不對，對比與點擊範圍低於 HIG。
