## 1. 為什麼有 v10

1. v9 的擺位對了，畫面感覺像 CAD 草模，v3 像柔光棚裡的黏土玩具。
2. 現況沒有影子，物件全是銳角方塊，顏色偏暗。
3. 加油機、Mart、垃圾桶、樹、agave、旗子缺 v3 的小細節。
4. 頁面只有一塊 debug 面板，sample 是作品頁加膠囊工具列。

## 2. 這次修訂改了什麼

1. 可行性審查：修 4 個會卡住的檢查、gate mode 光線不動、清掉塑膠反光、立體字三個陷阱。
2. 需求審查：配色、玻璃、旗子移到第 1 輪，面板擴到約 13 個參數並改樣式。
3. 加接觸陰影貼片，不用後製 AO，避免 draw call 爆掉。
