## 1. 為什麼有 v10

1. v9 的擺位對了，畫面感覺像 CAD 草模，v3 像柔光棚裡的黏土玩具。
2. 現況沒有影子，物件全是銳角方塊，顏色偏暗。
3. 加油機、Mart、垃圾桶、樹、旗子缺 v3 的小細節。
4. 頁面只有一塊 debug 面板，sample 是作品頁加膠囊工具列。

## 2. 最後會得到什麼

1. 柔光、軟影、暖色，雨棚與地面顏色接近 v3。
2. 左上標題、右側分組面板、底部工具列、抓手游標。
3. 灰方柱、圓角方塊、立體 CALTEX、較胖的道具。
4. 雙色加油機加油槍油管海報，Mart 有簷板與玻璃反光。
5. 有蓋有輪的垃圾桶、雙球樹、飄動的旗子、車道虛線。
