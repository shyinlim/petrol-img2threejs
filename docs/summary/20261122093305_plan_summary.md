## 1. 為什麼有 v7

1. 預覽頁的相機寫死，你不能用滑鼠旋轉。
2. 模型只做了參考圖那一面，轉到背面是空殼：旗子、roundel、招牌背面隱形，Mart 背面是白箱。
3. v6 只用參考圖那一個角度驗收，其他角度沒有標準。
4. 跟 v3 比，roundel 太大、樹太大、Mart 招牌太小、加油機偏紅、土層沒分層。
5. 預設相機比雨棚頂還高，所以雨棚看起來像暗橘厚塊，Mart 被擋住。

---

## 2. 最後會得到什麼

1. 預覽頁可以用滑鼠拖曳 360 度旋轉、滾輪縮放，點零件仍可選取。
2. 從 8 個角度看，每一面都有內容，沒有隱形面。
3. 比例更接近 v3：roundel、樹、Mart 招牌、加油機顏色。
4. 預設視角改成 v3 的低視線，看得到雨棚底板與 Mart 招牌。
5. 土層有分層紋理。
