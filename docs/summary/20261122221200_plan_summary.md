1. `src/main.ts` 單檔 636 行混雜場景初始化、17 個 Canvas 2D 貼圖函數、模型加工、Raycaster 選取與 UI 事件，難以閱讀與維護。
2. 專案缺少 `README.md` 與 `package.json` 的 `dev` / `build` / `preview` 啟動指令。
3. 需要確保重構後 3D 畫面、互動與所有 Python Playwright 驗收腳本 100% 正常運作。
